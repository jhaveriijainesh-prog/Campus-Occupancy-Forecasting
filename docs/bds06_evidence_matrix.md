## Verified Baseline Evidence

- Python regression: `176 passed`, `0 failed`, `643 warnings`; latest recorded execution was 45.87 seconds in `.venv-2`.
- Coverage: the existing `coverage.xml` snapshot reports an 86.48% line rate; it is not newly recomputed in this handoff.
- Forecast: XGBoost one-hour holdout MAE 1.2775, RMSE 4.3961, R2 0.8572, WAPE 50.52%, sMAPE 155.5725%; historical seasonal baseline MAE 2.5975, RMSE 10.1839, R2 0.2335.

- Clustering: 6 selected K-Means clusters; silhouette 0.4378954459.
- Scenario: one recorded run; WSH delta -1543.6, SUR delta +0.002845, RFU delta -0.008475, peak occupancy delta +33. These are tradeoffs, not a universal improvement.
- Optimization: one recorded CBC run, status Optimal, 50 assignments, objective 187.0, runtime 1.199315 seconds.
- Docker: full project build, exact `docker compose up --build -d`, API readiness, Streamlit, Compose-DNS API calls, authentication boundary, artifacts, and down/rebuild/restart were verified on 2026-10-01. No production hosting or external user trial is implied.
- Git/PR/review: unavailable because the workspace is not a Git repository.
- Browser screenshot/video: no final visual capture or recorded demo is evidenced.

## Final Traceability Rule

The local prototype, tests, and artifacts support technical claims only within their recorded scope. Missing stakeholder research, remote CI/Git history, actual contribution hours, recorded video, and institutional sign-off remain human-owned or external evidence; this matrix does not mark them complete.
