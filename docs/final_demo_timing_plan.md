# Final Demo Timing Plan

## Target duration
6 minutes 30 seconds to 7 minutes 30 seconds

## Timing structure
- 00:00–00:30: Title and problem
- 00:30–01:10: Problem + solution in plain language
- 01:10–02:00: System overview and local runtime
- 02:00–03:00: Overview dashboard explanation
- 03:00–04:15: Forecast Explorer and room selection
- 04:15–05:00: Forecast result and interpretation
- 05:00–05:45: Security, health/readiness, and leakage controls
- 05:45–06:20: Testing and reproducibility
- 06:20–06:50: Analytical clustering and optimization context
- 06:50–07:00: Limitations and conclusion

## Presentation rule
Keep the live narrative within the project’s verified scope and avoid “future features” language unless clearly framed as future work.

## Safety check
If the presenter runs long, trim the architecture and optimization explanation first. The forecast and live app flow remain the most important evidence.
